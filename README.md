# AXON — AI Workplace Assistant

**Author:** Rethabile Mokoena

**GitHub Repository:** https://snap-and-show-798.lovable.app/

## Project Overview

AXON is a modern, AI-powered workplace assistant designed to help professionals automate everyday workplace tasks. The application combines AI-powered email generation, task planning, research assistance, and workplace chat into one responsive SaaS-style platform.

AXON helps professionals save time and improve productivity by using AI to assist with common workplace activities.

The application provides four core AI tools:

* Smart Email Generator
* AI Task Planner
* AI Research Assistant
* AI Workplace Chat

AXON focuses on providing structured, professional, and actionable AI-generated outputs through a clean and intuitive interface.

The application is frontend-focused and does not use a custom backend, database, authentication system, or user data storage.

## Features Implemented

### Smart Email Generator

The Smart Email Generator creates professional workplace emails based on the user's requirements.

Features include:

* Email purpose and content input
* Audience selection

  * Client
  * Manager
  * Team
* Tone selection

  * Formal
  * Friendly
  * Persuasive
  * Assertive
* AI-generated subject line
* AI-generated email content
* Editable AI output
* Copy-to-clipboard functionality

### AI Task Planner

The AI Task Planner helps users create realistic and structured work schedules.

Users can create either daily or weekly plans by providing their tasks, priorities, available working hours, and optional deadlines.

Features include:

* Daily planning
* Weekly planning
* Task prioritisation
* Working-hour input
* Optional deadlines
* Calendar-style time blocks
* Automatic 15-minute breaks
* Time optimisation suggestions
* Workload management
* Conflict detection
* Suggestions to move, delegate, or eliminate tasks
* Structured and scannable schedules

The planner is designed to avoid unrealistic workloads and prevent users from being overloaded with too many tasks in one day.

### AI Research Assistant

The AI Research Assistant helps users quickly understand and analyse information.

Users can provide:

* A research topic
* A URL
* Pasted article or text content

The assistant can generate:

* Summaries
* Key insights
* Important points
* Practical recommendations

Research outputs are structured for easy reading and can be edited or copied.

### AI Workplace Chat

The AI Workplace Chat provides an interactive workplace-focused AI assistant.

Users can enter custom workplace prompts and receive contextual AI-generated responses.

Features include:

* Interactive chat interface
* Custom workplace prompts
* Dynamic AI responses
* Editable responses
* Copyable responses
* Clean conversation layout

### Dashboard

The AXON dashboard provides a central starting point for the application's AI tools.

It includes:

* Welcome section
* Quick access to the four AI tools
* Today's task overview
* Productivity summary

## Getting Started

### Prerequisites

Before running AXON locally, make sure you have the following installed:

* Node.js
* npm
* Git

### Clone the Repository

Clone the GitHub repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### Navigate to the Project

```bash
cd <PROJECT_FOLDER>
```

### Install Dependencies

Install the required project dependencies:

```bash
npm install
```

### Start the Development Server

Run the development server:

```bash
npm run dev
```

The terminal will provide the local URL where the application can be accessed.

### Build the Application

To create a production build:

```bash
npm run build
```

### Preview the Production Build

To preview the production build locally:

```bash
npm run preview
```

## AI Configuration

AXON uses AI-generated responses for its workplace tools.

If the project's AI functionality requires an API key or environment variable, configure it according to the AI provider's requirements.
